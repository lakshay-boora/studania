# Studania

**Free curated platform for JEE, NEET & UPSC aspirants.**

Notes • Formula Sheets • Best Lecture Videos • Previous Year Papers • Doubt Hub

## Live Demo
After deploying to Vercel: your-project.vercel.app

## Features
- Completely free
- Clean, modern, student-friendly design
- Dark / Light mode
- Mobile responsive
- JEE Main & Advanced
- NEET UG
- UPSC CSE
- Doubt Hub (frontend preview)

## How to Deploy on Vercel (1 minute)
1. Go to [vercel.com](https://vercel.com)
2. Click "Add New Project"
3. Import the GitHub repo `lakshay-boora/studania`
4. Click Deploy

That's it. Your site will be live.

## Local Preview
Just open `index.html` in a browser.
